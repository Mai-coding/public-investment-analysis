# 14 · 章节深度配方（Depth Playbook）

> 核心命题：**章节不够详细，根因不是字数少，而是"深度结构"缺失**——原文多为"陈述 + 形容词"，缺数据、缺因果、缺对追问的预答。本配方把"加详细"操作化。

---

## 一、写作层：四条深度准则（自然散文，不要贴标签）

> ⚠️ **旧版这里是"CEMRI 五件套（C 断言 / E 证据 / M 机制 / R 反方 / I 启示）"——已废弃。** 用户明确要求**全文不套 CEMRI、不贴 `[C][E][M]` 标签**，写连贯自然散文。但"加详细"的实质不变：每次"加详细"的返工，本质都是在补**数据、因果、反面**。把下面四条**写进句子**，而不是做成填表：

1. **有数字**：每个判断后面立刻跟一个量（GW / 美元 / % / CRn / 倍数 / 年份 / 份额），杜绝"陈述 + 形容词"。
2. **讲清为什么**：结论要顺带说清它为什么成立的机制（如"因为 NRC 审批 10 年+、退役基金、近 20 年无新建，所以现役核电 CR3>80%"），用自然句子带出，不标"机制"二字。
3. **点出反面**：关键判断顺手点一句风险 / 边界 / 反例（如"但 SMR 2030s 可能边际稀释"），让结论有攻防、不单边喊多。
4. **落到投资含义**：说清这对估值 / 评级 / 跟踪意味着什么。

> 一句话：好段落 = 结论 + 数字 + 为什么 + 风险 + 对投资的含义，**写成流畅的话**，不是五个带标签的格子。反例（不合格）："核电是壁垒。"——空泛。正例（合格）："壁垒来自现役牌照的稀缺：全美 94 台/97GW、CEG 22.8GW、VST 6.4GW，而 NRC 新建审批 10 年+、近 20 年无新机组，使竞争性核电 CR3 超 80%；虽然 SMR 在 2030s 或边际稀释，但中期现役牌照不可替代，是估值溢价的来源。"

### 1.1 必答/指导性问题：写成陈述句，不要把问号搬进报告 ⚠️

reference 文件里以**问句**形式列出的"必答问题"（如 §4.5 用户视角、§6.3 行业挑战、§8.5 利润率、§8.6 壁垒、§9.2–9.4 团队）是**给分析者思考的指引**，不是让模型把"Q1：…？"照搬进报告。**报告正文里子节标题与段落不得出现 `Q1：` / `？` 开头的问句**——把答案糅进陈述句段落（每段约 150–200 字）。

- ❌ 错（保留问句）：`Q1：用户觉得是必须品，还是可有可无？\n对 AI 数据中心客户而言…`
- ✅ 对（陈述句）：`对 AI 数据中心客户而言，800G/1.6T 光模块是必须品，不是 nice-to-have——AI 训练集群规模扩张要求 GPU 间光互联带宽必须同步提升…`

> 交付前 grep 子节标题位置的 `Q1：` / `Q2：` / `？` 应为 0（最终由 `scripts/depth_audit.py` 检查，人工写作审查见 `10_final_checklist.md`）。各章具体题目见对应 `sections/03a–03d` 切片（如 §4.5 的三个指导性问题）。

---

## 二、量化纪律：每个定性词都要挂一个数字

- 出现"大 / 快 / 集中 / 稀缺 / 领先 / 便宜"等形容词时，**后面必须立刻跟一个量**：GW、美元、%、CRn、$/单位、倍数、年份。
- 市场规模**一律美元化**（不能只给 TWh/GW/吨）：TAM/SAM/SOM 给"美元/年" + 标的份额 + 份额轨迹。
- 份额要区分**名义总量 vs 可寻址真实分母**（例：全美核电 97GW 是名义量；能签 merchant PPA 的"竞争性核电"仅 ~35–40GW 才是真实分母）。

---

## 三、预答追问：每章只挑 2–3 个"最尖"的，但每个都要深答

写完每章，自问"读者会追问什么"，但**不要罗列一堆**——**每章固定挑 2–3 个最关键的追问**（投资人真正会卡住、答错就推翻结论的那种），其余不写。**质量 ≫ 数量：宁可 2 个深答，不要 5 个浅答。**

**选题标准（什么算"尖"问题）**：① 答案会改变投资结论或评分；② 是该标的/行业**特有**的争议点（不是放之四海皆准的套话）；③ 一句话答不了、需要数据+因果。把"必须品还是可选""客户体验如何"这类**软问题剔除**。

**回答的质量门槛（每个追问必须满足）**：
- 用**自然散文**完整回答（结论 + 数字 + 为什么 + 风险 + 投资含义，**不贴标签**），≥1 段；
- 含 ≥1 个硬数字 + ≥1 条因果链 + ≥1 个反方/边界；
- 复杂追问（市场/份额/替代/集中度）**配一张表**；
- 与其它章节**交叉印证**（指明"详见 §X"），形成自洽逻辑网。

**通用追问题库**（从中**选 2–3**，不是全做）：
- A. 这个壁垒/优势**具体有多少**（数量/容量/金额/份额）、谁还有、凭什么不可复制？
- B. 这个利好**为什么是本标的受益、而非替代品**？（"为什么非核电不可"式）
- C. 这个利好**会不会逆转/何时减弱**、早期信号是什么？（"瓶颈 27 年后是否缓解"式）
- D. 新技术/新进入者**会否替代它**？成本、时间线、标的如何应对？（"SMR 是否替代现役"式）
- E. 大客户/对手方都有谁、**各下多大单、何时兑现、多少钱**？市场看似不集中是否成立？
- F. 把市场**换成美元**有多大、标的现在/未来占多少？

> 每章把选中的 2–3 个追问做成**独立小节或独立段落**（见对应 section slice 的“最低产出物 + 预答追问”），可一次性消灭 80% 的返工。

## 四、研究层：先建"证据表"，再写散文（深度上限由数据决定）

**开写前先填表**，散文只是"把表讲成故事"：

- **数量化全景表**：总量 / 各玩家 / 份额 / CRn / 可寻址真实分母。
- **时间线 + 金额表**：谁、何时、多少 MW/吨/单元、多少钱、何时兑现。
- **单位经济学表**：$/单位（$/MWh、$/kW、LCOE、$/吨），用于成本与替代对比。
- **美元市场表**：TAM/SAM/SOM（美元/年）+ 标的份额 + 轨迹。

没有表，就别写该子节——这是"硬性研究门槛"，不是建议。

---

## 五、深度的最小量化标准（用于自检）

一个子节**合格**的最低线：
- [ ] ≥1 个具体数字（带单位/来源/年份）
- [ ] ≥1 条因果机制（"因为…所以…"）
- [ ] ≥1 个反方/边界/风险
- [ ] 若是"市场/份额/壁垒/竞争/技术替代"类 → 必须配 ≥1 张表

不满足 → 标红回炉，不得交付。

---


## 六、Few-shot 使用规则

公开包不捆绑特定公司的 few-shot，以免把旧公司事实误当成当前标的证据。需要校准产品分析结构时，使用 `sections/03a_research_sections_2_9.md` 的 §4 清单，并以当前标的的一手资料写作；不得从历史案例复制公司事实。
