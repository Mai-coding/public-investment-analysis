# 21 — 中文研报正文、数字与封面

本文件统一读者展示层；模型、证据底稿和方法附录保留原始精度。只加载当前任务需要的规则，用户要求优先。

## 正文组织

- 默认先技术/业务入门，再行业与公司历史；按知识依赖安排阅读顺序，先解释后使用术语。章节内容清单见 `sections/03a_research_sections_2_9.md`。
- **介绍性文字**按概念依赖、业务流程或事件因果围绕一个问题展开。后一段须承接、解释、限定或推进前文；随机调换段落仍不影响理解，通常说明只拼接了知识卡片。连接词不能替代逻辑关系。
- 陌生概念先直白定义，再解释原理及业务关系；类比仅在有助理解时使用，之后回到真实机制。历史串起当时约束、关键选择及后果。不强制每段数字、反方、估值或交易结论，不靠删去必要解释换取简短。
- **分析性文字**以判断开头，用关键事实、机制和边界解释对盈利、估值或行动的影响，参考高盛研报的论证密度。区分公司披露、我们的预测和条件情景；不机械套句式或逐行复述表格。
- 决定性成本、价格和效率数字须有可理解的参照，说明高低、差异原因及商业影响。比较保留年份、单位、服务条件和成本组成；不由资本回收等局部数字推断完整项目回报。
- 首次分析重大且不直观的收入/成本，先讲清交易、资源与风险如何流转，再分析利润。必要的业务解释留正文，详细定义、统计边界、期间桥接、换算、去重、会计对账及算式放 Methods。
- 正文给综合观点与事实，不写研究过程、“口径为/口径差异/统一口径后”或 Fact/Inference/Assumption 标签。逐篇素材比较和验证过程入 Methods；会改变投资判断的分歧、不确定性、关键假设和触发条件仍须在正文可见。
- 中文表格/图表与正文遵守下列单位和精度；引用使用数字上标，格式由 `20_citation_and_source_appendix.md` 管理。

## 数字：先换单位，再决定小数位

1. **最多一位小数；换算后绝对值 ≥10 一律不留小数，绝对值 <10 才可保留一位。** 整数不补 `.0`，负数按绝对值判断。四舍五入采用 ROUND_HALF_UP；9.96 显示为 10，不显示 10.0。
2. 百分比按百分数判断：24.36% → 24%，6.74% → 6.7%；百分点同理，2.36 个百分点 → 2.4 个百分点。倍数、股价、每股数据、评分同样适用：23.64 倍 → 24 倍，198.875 美元 → 199 美元，6.74/10 → 6.7/10。
3. 正文、表格、图表大数使用**万、亿**，金额明确币种，人数/台数/股数明确实物单位；不用百万、十亿、million、billion、m/bn/B 等缩写。1 million = 100 万；1 billion = 10 亿；1 trillion = 10,000 亿。例：11.5 billion USD → 115 亿美元，1.5 trillion USD → 15,000 亿美元，50,200 台 → 5 万台。
4. 同一张表的同类列/同一图轴固定单位，在表头写“收入（亿美元）”“用户（万人）”；只允许数值精度自适应，不逐行换单位。不同量纲分列。同类数据跨图表尽量保持单位一致。单独引用的数字必须带单位。
5. 非零极小值不得显示为 0：小于一位小数的可表达范围时写 `<0.1%`、`不足 0.1 亿美元` 等，或为整列选择更小单位。真零写 0，缺失写 `—`，负数不得因舍入变成零。不得捏造多余精度。
6. 换单位只缩放数值，不换币种；`$` 与“美元”不重复混用。中文正文优先写“115 亿美元”“199 美元/股”。保留单位换算和汇率的全精度记录于模型与方法附录。
7. 所有计算、估值、排序、触发判断先用**全精度**模型值，最后才格式化。正文写“约”表明舍入；表格尾差由方法附录说明，不人为改某一行凑总数。若四舍五入会改变买卖阈值判断，正文说明“以附录精确阈值为准”，附录保留精确值；不能依据显示值判断动作。
8. 年份、日期、股票代码、版本号、章节号、来源标题/引用编号不是财务数值，不做舍入。方法附录的审计值可保留必要精度。此规则不改变 Excel 原始存储单位、公式或内部诊断页；复制到报告时必须转换。

可复用 `scripts/report_presentation.py` 的 `format_number` / `format_amount` / `format_percent`，或以相同行为实现。图表直接把格式化器用于刻度和标签，不对模型输入先 round。

## 首页：公司识别 + 判断层次 + 克制留白

参考用户提供的 Marvell 首页截图的蓝色眉题、公司大标题、灰色判断副标题、深蓝判断条和留白；参考高盛样张的结论密度与加粗段首。保留本技能的 Price Band Decision Map，截图中的 SELL、单一目标价和旧估值加权不成为新要求。

建议 A4 单页，页边距 18–22 mm；按以下顺序组织：

| 区域 | 内容与排版 |
|---|---|
| 顶栏 | 左侧蓝色 `EQUITY RESEARCH｜公司深度研究`，右侧**目标公司真实 logo**，宽约 25–35 mm、高不超过 14 mm；独立段落/定位区域，不放入判断表 |
| 公司标题 | 公司中英文名称，约 28 pt；与 logo 保持间距，长公司名自然换行 |
| 判断副标题 | 16–20 pt、灰蓝色，一至两行写出最重要的投资判断；避免空泛宣传语 |
| 基本信息 | 交易所/代码、报告日期、现价与快照日期、市值；9–11 pt，金额遵循上述中文单位 |
| 三列判断卡片 | **共两行三列：一行表头 + 一行内容**。表头依次为 **价格 / 回报 / 综合判断**。价格列列出现价与基准情形价格/价格带；回报列只列基准情形三年年化总回报（含分配），不混入其他情景或入场价；综合判断列保留简短结论，可含评分与置信度。表头统一用色板 NAVY（#061F32）白字，内容浅灰底；全部文字 **12 pt**，水平垂直居中，不缩字硬塞；不另加“当前行动”第三行，行动解释进入正文 §1 |
| 核心论点 | 两至三段短论证：盈利驱动、市场预期差、主要风险/改判条件；正文约 11 pt，加粗少量判断句，数字上标引用 |
| 页底 | 关键入场条件或跟踪信号，少量蓝色强调；完整研究基础、来源清单、方法说明进入附录 |

- 色板继续读取 `assets/color_palette.json`，字体继续按 Task 5 的楷体 + Times New Roman；不因参考版式替换已有字体和图表系统。
- Logo 获取与记录遵循 `17_product_images.md` 的“封面公司 logo”。不得使用高盛 logo、分析师签名或原报告水印，不得暗示机构出品。
- 不放大 logo 占据版面，不加无关装饰，不拉伸、不重绘品牌标志。保留干净背景和纵横比。不能复制样张中的过时事实、日期或投资建议。
- 必须渲染检查：封面确为一页、logo 清楚、标题不相撞、三列卡片无裁切、正文留白均衡。长标题或多行卡片先缩短措辞/调整间距与列宽，不缩小卡片字号。

## 全报告表格

- 封面、正文和附录的数据表第一行统一使用 `assets/color_palette.json` 的 NAVY（#061F32）底色、白字；显式写入单元格底色与文字颜色，去除冲突的主题色。纯图片布局容器不当作数据表头。
- 所有表格文字（含表头、数据、说明、合并单元格）水平与垂直居中。每个含文字的段落设 `w:jc=center`、单元格设 `w:vAlign=center`，不只居中表格本身；封面全部文字仍为 12 pt。这不改变 Excel 模型的对齐规则。
- 封面现价、基准价格带与回报直接读取同一模型及快照；有多个基准端点时优先显示价格带，单值须标明 Base midpoint。不得把入场上限冒充基准价格；缺失值说明原因，禁止补造数字。

## 标题、目录与导航

- 保留 Word 原生 Heading 1–3 / outline level 0–2。一级标题用色板 NAVY，二级 BLUE，三级 SLATE；中文楷体，英文与数字 Times New Roman。标题颜色须显式指定，去掉会覆盖颜色的 themeColor；字号见 Task 5/视觉规范。
- 一级标题默认 `§2 核心技术入门`，二级 `2.0 背景知识`，三级 `2.1.1 …`；保留一致的既有编号或用户格式也可。不得附加小黑方块或项目符号；标题的语义层级不能为了隐藏标记而改成普通正文。
- 封面后放目录，正文各章、每个可比公司附录、Methods 和 Sources 各有一条编号/标识、标题、页码及内部跳转。正文序号跟随实际章节，附录用 A–E / M / S 等清楚区分的标识；不硬编码条目数。Word 导航窗格保留同样的真实标题层级，目录条目不得成为重复正文标题。
- 目录全部页码（含附录、Methods、Sources）统一显式使用 NAVY（#061F32），覆盖 Hyperlink/TOC/PAGEREF 的默认或主题颜色；访问链接后也保持一致。最终分页后刷新目录/PAGEREF，再核对页码颜色、跳转与实际页码；XML 缓存不能证明分页准确。
- 标题及所有图片所在段落前均不得有小方块或项目符号；按 `22_docx_layout.md` 排查字符、列表、字体和段落属性。修复后检查 Word 与分页，不以关闭编辑标记或 PDF 外观作为已修复的证明。

## 附录分工与校验

正文 §1–16 → 可比公司附录 A–D/A–E → `Appendix｜Methods / 定义与方法` → `Appendix｜Sources / 来源索引`。Methods 不编号为新的可比公司附录，且不计入正文/可比公司深度下限；Sources 保持最后。

Methods 建议按“指标定义与统计边界 / 数据期间与换算 / 会计对账 / 模型与估值推导 / 精确决策阈值”组织，只列本报告用到的内容。来源编号仍统一由 Sources 解析。

`report_content_audit.py` 检查正文小数位、禁用大数单位、口径措辞、Methods 在场与顺序以及真实嵌入的 `COMPANY_LOGO:` 图片；它不能判断论证质量或证明品牌素材真实性。人工 QA 核查单位换算、官方出处、表头/坐标轴、舍入后决策含义和完整渲染。Quick memo 不强制全报告的结构闸门，但同样执行这些展示规则。
