# Recipe 18d — 推导式技术分析

仅在分析技术壁垒时读取。每条重要优势从约束与客户要求出发，推到成立条件，用可验证证据支持，并指出替代方案何时更好、优势何时失效。标题表达实际判断，不强套“推导N”或预设唯一解。

- 约束：物理、工程或经济条件怎样限制可选方案。
- 选择：在什么成本、时间、可靠性等要求下，客户更可能采用标的方案。
- 证据：参数、运行记录或财务结果如何支持判断；相关性不自动等于因果。
- 边界：关键未决前提、可替代路径、失效后果及早期信号，与每条壁垒对应。

关键数字的参照遵循 `../21_report_editorial_style.md`；结论连接竞争力评分及估值分歧变量。读者应能沿推理提出异议，不能用材料原文的形容词替代论证。
