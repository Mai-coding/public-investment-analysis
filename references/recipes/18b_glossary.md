# Recipe 18b — Single Consolidated Glossary (§2 end)

> This is the only glossary in the report. §3 explains a term briefly on first use but does not carry a second terminology table.

1. Put one two-column glossary at the end of §2: `术语`｜`一句话解释（含类比）`.
2. Merge aliases and near-synonyms into one primary entry, with aliases in parentheses; do not repeat PAM4/PAM-4, Optical I/O/光 I/O, etc. as separate rows unless economically distinct.
3. Include technical acronyms/industry jargon used in the report plus only the financial terms a non-specialist actually needs.
4. Explain each entry in ≤30 Chinese characters where feasible, without using an undefined term.
5. Order by first appearance or theme, not alphabetically. Typical range 15–25 entries; quality and coverage matter more than count.
6. Before delivery, scan §3 and fail any heading/table named `行业术语速览`, `术语表` or `Glossary`; `report_content_audit.py` enforces this placement.
