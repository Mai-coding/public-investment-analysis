# Recipe 18c — Value Chain Deep Dive (§3.8)

> Load this self-contained recipe only when writing the named section; no legacy collection is required.

## 配方三：价值链全景（升级 §3 的上下游小节）

**目标**：从"罗列上下游玩家名单"升级为"读者看懂钱在链条上怎么分"。

**硬性规格**：
1. **环节表**（强制，4 列）：「环节」｜「这个环节做什么」（给非技术读者的一句话）｜
   「主要玩家」（具名，含市占格局一笔）｜「商业模式与议价权」（毛利率量级+定价权来源）。
   环节数 5-8 个，从最上游（芯片/原材料）到最下游（应用/终端客户）全覆盖，target 所在
   环节显式标注（如"NET 主场/NET 卡位"）。
2. **价值分布图**（强制出图）：第一选择是目标公司同口径、同年份的分部收入、EBITDA和Capex，
   图表与正文写明每个指标的分子/分母/年份/准确来源。用收入组合、利润贡献、资本占用和利用率共同
   判断价值分布，不把收入增长单独等同于价值迁移。只有目标公司未披露足够分部数据时，才用各环节
   代表公司 10-K 毛利率作跨公司代理；此时须标 `Inference`、列代表公司与年份并写清可比性限制。
3. **"谁赚走了钱"分析段**（强制）：解释价值分布的成因——为什么有的环节高
   （稀缺性/垄断/网络效应）、有的环节低（标准化/商品化），并给出 target 的
   **迁移路线**：它正从哪个环节向哪个环节爬、用什么手段、财务上如何验证。
   每个迁移结论必须由同公司分部收入/EBITDA/Capex/利用率中的至少一个指标支持；跨公司毛利率
   只能辅助解释行业利润池，不能单独证明目标公司已完成迁移。
4. 上中下游都要有"对 target 的意义"，不写无结论的名单。
