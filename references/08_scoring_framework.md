# 08 - 5 维度评分框架（上市公司，固定权重）

本 skill 只评上市公司，**不区分投资轮次/阶段**，使用一套固定权重。

## 5 个维度

| 维度 | 评分依据 |
|------|---------|
| **市场吸引力** | TAM 规模 / SAM 增速 / 渗透率 / 行业拐点 |
| **竞争力** | 技术壁垒 / 全栈布局 / 市场份额 / 护城河 |
| **商业模式** | 单位经济学 / 订阅化 / 客户集中度 / 现金转化 |
| **团队** | 创始人 + 高管 + 工程文化 / 关键人风险 |
| **估值** | 目标价 vs 现价（上行空间）/ 相对可比 forward P/E·P/S 折溢价 |

## 固定权重（上市公司）

| 维度 | 权重 |
|------|------|
| 市场吸引力 | 25% |
| 竞争力 | 25% |
| 商业模式 | 15% |
| 团队 | 15% |
| 估值 | 20% |
| **合计** | **100%** |

> 如某些行业需要微调权重（如重资产 vs 轻资产），可在报告中说明理由后调整，但默认用上表。

## 评分标尺（0-10）

| 分数 | 含义 |
|------|------|
| 10 | 行业 top 1，无可比 |
| 8-9 | 明显领先，有显著优势 |
| 6-7 | 平均水平，有局部优势 |
| 4-5 | 弱于平均，有局部劣势 |
| 2-3 | 显著弱势 |
| 0-1 | Critical issue，几乎不能投 |

## 评级规则：评级由上行空间决定，评分作支撑（单轨制）⚠️

**评级（BUY/HOLD/SELL）由 Task 3 的 12 个月目标价上行空间唯一决定**；加权总分是交叉支撑证据，不是第二套评级体系。

### 上行空间 → 评级映射（主轨）

| 12 个月上行空间 | 评级 |
|----------------|------|
| ≥ +15% | BUY |
| −10% ~ +15% | HOLD |
| < −10% | SELL |

### 评分 ↔ 评级一致性对照（支撑轨）

| 加权总分 | 与评级的预期对应 | 冲突时怎么办 |
|---------|----------------|-------------|
| ≥ 8.0 | 通常对应 BUY | 若上行空间 < +15%（好公司贵价格）→ **评级仍按上行空间给 HOLD**，14.2 注明"质地优、估值满" |
| 7.0-7.9 | 通常对应 HOLD | 若上行空间 ≥ +15%（平庸公司便宜价格）→ 评级 BUY，14.2 注明"估值驱动而非质地驱动"，并复查 Bear 情景 |
| < 6.0 | 通常对应 SELL/回避 | 若上行空间为正 → 先怀疑自己的目标价假设，回查 Task 3 |

**纪律**：评分与评级出现档位冲突时，**以上行空间为准**，且必须在 14.2 用一段话解释分歧来源（质地 vs 价格），不得静默二选一。

## 评分必须与第 12 章目标价一致

- 若上行空间为负或很小（接近现价），**估值维度不能给 > 5 分**。
- 若上行空间显著为负，估值维度应给 2-4 分。
- 防止"高分 + 看空"或"低分 + 看多"的逻辑矛盾。

## 评分维度细化

### 市场吸引力
- TAM > $1T，增速 > 20% → 9-10 分
- TAM $100B-1T，增速 10-20% → 7-8 分
- TAM $10-100B，增速 5-10% → 5-6 分
- TAM < $10B 或衰退 → 3-4 分

### 竞争力
- 全球 #1 + 难以撼动 → 9-10；中国 #1 / 美国 #2 → 7-8；区域 #2-3 → 5-6；二线 → 3-4

### 商业模式
- 高 LTV/CAC（>5x）+ 订阅化 + 客户分散 → 9-10；项目制 + 高客户集中 → 5-6；一次性销售 + 大客户依赖 → 3-4

### 团队
- 连续创业者 + 稳定 + 强执行力 → 9-10；强创始人 + 部分高管空缺 → 6-8；不稳定 / 错配 → 3-5

### 估值
- 目标价较现价上行 30%+ 且低于选定中央可比锚 → 9-10
- 目标价接近现价 / 估值接近选定中央可比锚 → 6-7
- 目标价低于现价（下行）/ 估值高于选定中央可比锚 30%+ → 3-4
- 显著高估（下行 + 估值高于选定中央可比锚 100%+）→ 1-2

异质全样本中位数不得用于估值评分；多分部标的以分部SOTP中央锚为准。
