# 08 - 5 维度评分框架（上市公司，固定权重）

本 skill 只评上市公司，**不区分投资轮次/阶段**，使用一套固定权重。评分是质地与估值位置的交叉支撑，**不决定投资结论**；结论由 `05_valuation_methodology.md` 的 Price Band Decision Map 给出。

## 5 个维度

| 维度 | 权重 | 评分依据 |
|------|------|---------|
| 市场吸引力 | 25% | TAM 规模 / SAM 增速 / 渗透率 / 行业拐点 |
| 竞争力 | 25% | 技术壁垒 / 全栈布局 / 市场份额 / 护城河 |
| 商业模式 | 15% | 单位经济学 / 订阅化 / 客户集中度 / 现金转化 |
| 团队 | 15% | 创始人 + 高管 + 工程文化 / 关键人风险 |
| 估值 | 20% | 市场计入与证据支持档位的差异 / 3 年预期回报 / 终局要求的容错空间 |
| **合计** | **100%** | |

> 行业需要微调权重（如重资产 vs 轻资产）时，在报告中说明理由后调整。

## 评分标尺（0-10）

| 分数 | 含义 |
|------|------|
| 10 | 行业 top 1，无可比 |
| 8-9 | 明显领先，有显著优势 |
| 6-7 | 平均水平，有局部优势 |
| 4-5 | 弱于平均，有局部劣势 |
| 2-3 | 显著弱势 |
| 0-1 | Critical issue，几乎不能投 |

## 结论与评级（secondary）

- **不设"12 个月上行空间 ≥X% = BUY"之类的固定阈值。** 核心结论 = Current Price Band + Expected 3Y Return + Risk/Reward + Actionability + What would change the conclusion。
- 如用户或模板需要评级，只作 secondary output，由 actionability 与 thesis 状态映射（如 Initiate/Accumulate ≈ 正面，Hold/Wait ≈ 中性，Trim/Avoid ≈ 负面），并注明"评级从属于 Price Band 结论"。
- 评分与结论冲突时不得静默二选一，在 §15 用一段话解释分歧来源：高分 + 现价位于 Base+/Upside 带 = "质地优、估值已反映"；低分 + 低价带 = 先检查 thesis 是否已被证伪，再判断是否 Conditional。

## 估值维度必须与 Price Band 和条件证据一致

- 现价位于 Upside/Re-rating 带或 3 年预期回报低于门槛回报 → 估值维度 ≤ 5。
- 现价位于 Base 带且 3 年回报约等于门槛 → 6-7。
- 现价位于 Disappointment 带、thesis 完好且 3 年回报显著高于门槛 → 8-10。
- 现价位于 Thesis Impairment 带 → 估值分不得因"便宜"而拉高，须同时参考 thesis 验证状态。

上述位置规则须以 Evidence-supported Band、thesis 状态与门槛回报共同核验；不能仅因价格处于某档自动赋分。市场已计入乐观而证据只支持基准时，须明确差距。

异质全样本中位数不得用于估值评分；多分部标的以分部 SOTP 中央锚为准。

## 评分维度细化

- **市场吸引力**：TAM > $1T 且增速 > 20% → 9-10；$100B-1T、10-20% → 7-8；$10-100B、5-10% → 5-6；< $10B 或衰退 → 3-4。
- **竞争力**：全球 #1 且难以撼动 → 9-10；中国 #1 / 美国 #2 → 7-8；区域 #2-3 → 5-6；二线 → 3-4。
- **商业模式**：高 LTV/CAC（>5x）+ 订阅化 + 客户分散 → 9-10；项目制 + 高客户集中 → 5-6；一次性销售 + 大客户依赖 → 3-4。
- **团队**：连续创业者 + 稳定 + 强执行力 → 9-10；强创始人 + 部分高管空缺 → 6-8；不稳定 / 错配 → 3-5。
