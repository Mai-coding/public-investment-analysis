# 07 - Killer Risk 矩阵框架

## 分级体系（3 档，弹性区间 + 宁缺毋滥）

| 等级 | 颜色 | 影响 | 数量（弹性） |
|------|------|------|------|
| 归零级 | 红 | 项目可能归零 | 0-3 个 |
| 重大 | 橙 | 目标价下行 30%+ | 3-6 个 |
| 影响回报 | 蓝 | 目标价下行 5-15% | 2-4 个 |

合计 **6-13 个**为弹性区间，不是硬性配额。

**宁缺毋滥纪律**：
- **不得为凑数制造伪风险**——成熟稳定公司（现金牛、低杠杆、客户分散）的真实归零级风险可能是 0-1 个，硬凑 2-3 个只会稀释真风险的注意力。
- 归零级少于 2 个时，用一句话说明为何无更多归零级风险（这本身就是结论）。
- 每条风险必须通过测试："如果它发生，目标价/评级怎么变？"——答不上来就删。

## 评估维度

每个风险标 2 个数：
- **发生概率**：0-1 (low / medium / high / very high)
- **影响烈度**：0-1 (可忽略 / 影响回报 / 重大 / 归零级)

矩阵象限：
- **KILLER ZONE**（右上）：高概率 × 高影响 — 必须有 mitigant
- **Tail Risk**（左上）：低概率 × 高影响 — 监控
- **Manage**（右下）：高概率 × 低影响 — 已纳入测算
- **Monitor**（左下）：低概率 × 低影响 — 可忽略

## 每个风险必备 4 要素

1. **风险描述**：1-2 句话
2. **发生概率估算**：低/中/高 + 数字
3. **影响烈度**：归零/重大/影响回报
4. **Mitigant**：如何缓解
5. **早期预警信号**：什么指标会触发

## 通用风险类别（按行业适配）

| 类别 | 典型风险 |
|------|---------|
| 技术 | 核心技术失败、量产延期、性能不达标 |
| 关键人 | 创始人离职 / 健康 / 精力分散 |
| 监管 | 出口管制、反垄断、行业新规 |
| 客户集中 | Top 3 客户流失 |
| 竞争 | 巨头介入、新技术颠覆 |
| 地缘 | 中美脱钩、贸易战、制裁 |
| 资本 | 资本市场关闭、融资难 |
| 财务 | FCF 转正延期、Capex 失控 |
| 供应链 | 关键原材料断供 |
